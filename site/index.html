내 손에 맞는 Finder,
터미널과 함께.

Gifiles는 macOS Finder의 사용감을 그대로 옮긴 macOS·Windows·Linux 파일 관리자입니다. 목록 아래 터미널이 목록과 맞물려 움직이고, 모든 기능을 키보드로 다룰 수 있으며, 네이티브(Qt)로 만들어 가볍습니다.

특징

목록과 맞물린 터미널

파일을 터미널로 끌어 놓으면 따옴표 친 경로가 입력되고, 입력 중인 명령은 절대 덮어쓰지 않습니다. 크롬처럼 터미널 탭도 씁니다.

Finder 그대로의 키보드

⌘1 갤러리 · ⌘2 목록 · ⌘3 컬럼, Space 미리보기, Return 이름 바꾸기. 모든 단축키는 설정에서 바꿀 수 있습니다.

빠른 미리보기

이미지·영상·음악·PDF·코드를 바로 보고, 오피스 문서는 운영체제의 미리보기를 그대로 씁니다.

선택한 항목으로 명령 · AI

고른 파일에 내 스크립트나 AI 요청(claude, codex 등)을 바로 실행합니다. 경로는 셸에 맞게 안전하게 감쌉니다.

모든 작업 되돌리기

복사·이동·이름 바꾸기·삭제를 ⌘Z로 되돌립니다. 지우는 건 언제나 휴지통으로 갑니다.

설정 파일 하나, 자동 업데이트

모든 설정은 설명이 달린 config.toml 하나에 있고, 새 버전은 서명을 확인한 뒤 알아서 받아 둡니다.

다운로드

최신 버전 받기GitHub Releases macOSApple Silicon · Intel 공용 · 서명·공증된 앱 (zip) Windowsx64 · zip을 풀고 Gifiles.exe 실행 Linuxx86_64 · AppImage (실행 권한을 주고 실행)

한 번 설치하면 앱이 새 버전을 확인해 받아 두고, 종료할 때 설치합니다. Windows 앱은 서명되지 않아 처음 실행할 때 경고가 뜰 수 있습니다(추가 정보 → 실행).

개인이 만들어 무료로 공개하는 앱입니다. 자유롭게 쓰셔도 되지만 기능 제안, 버그 신고, 사용 지원은 받지 않습니다. 원하는 기능이 있으면 MIT 라이선스에 따라 포크해서 고쳐 쓰세요.
